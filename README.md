# GH_300T00
Since you don’t have access to Udemy or Tutorials Dojo, we’re relying only on free resources:
-	Microsoft Learn official modules (GitHub Copilot Fundamentals Part 1 & 2)
-	GitHub Docs on Copilot (https://docs.github.com/en/copilot)
-	Free official Microsoft practice assessment → Gives you ~50 questions in exam style (access here: https://learn.microsoft.com/en-us/credentials/certifications/github-copilot/ — scroll to “Practice for the exam” and click “Take the practice assessment”)
-	Exam sandbox → Free way to see the real interface (https://go.microsoft.com/fwlink/?linkid=2226877)
-	Self-generated practice → Use your own Copilot in VS Code to create/test scenarios + ask it to quiz you on topics
-	Additional free samples → Sites like examtopics.com (limited free questions visible without account), testpreplab.com (some GH-300 free questions), or edusum.com (sample set) — browse these for 10–20 extra questions per week if needed
Core focus: Hands-on Copilot usage (your strength) + official docs + the free Microsoft practice assessment (repeat it 2–3 times in later weeks).

Goal: Core features, plans, triggers
-	Mon–Fri (two 30-min sessions):
  1.	Microsoft Learn intro modules + Copilot plans (Individual/Business/Enterprise differences)
  2.	Hands-on: Setup/test in VS Code + basic chat/inline
•	Sat (four 30-min): Git basics review → Watch short overview → Generate 5–10 snippets → Quick self-quiz (ask Copilot 10 questions)

•	Mon–Fri (two/three 30-min):

2.	Rewrite/improve 3–5 of your real past prompts
•	Sat: Advanced (multi-step, few-shot) → Test in 2nd language → Self-quiz (Copilot-generated questions)
Week 3 (Jan 19–24) — Advanced Usage & Multi-Language

•	Mon–Fri:
1.	Copilot across languages + triggers (chat/inline/CLI)
2.	Generate/test in 2–3 languages
•	Sat: Testing/debug output → Scenario practice → Self-quiz
Week 4 (Jan 26–31) — Governance, Security & Plans
Goal: Privacy, IP, exclusions, org settings
•	Mon–Fri:
1.	Read governance/privacy sections (Docs + Learn)
2.	Review your code for best practices
•	Sat: Security risks → Plan comparisons → Combined practice → Self-quiz
Week 5 (Feb 2–7) — Responsible AI + Testing

•	Mon–Fri:
1.	Responsible AI principles + limitations
2.	Write tests for Copilot-generated code
•	Sat: Ethics deep dive → Testing workflows → Take full free Microsoft practice assessment (repeat weak areas)
Week 6 (Feb 9–14) — Review & Mocks
Goal: Simulate exam
•	Mon–Fri (two 30-min):
1.	Review weak topics (from practice assessment)
2.	Timed self-quiz (10–15 questions/day — Copilot or free sites)
•	Sat: Retake Microsoft practice assessment → Thorough review → Light cheat sheet polish
Final days (Feb 15–17): Light review of notes → Take exam!
Quick Tips
•	Build a 1-page cheat sheet: Plans comparison, prompt tips, responsible AI key points, privacy exclusions
•	In Weeks 5–6, prioritize the official free practice assessment — repeat it to track improvement
•	Use Copilot itself to generate practice questions on weak topics (e.g., “Quiz me with 10 multiple-choice questions on Copilot Business plans”)
•	Your 3 months of real usage is a huge advantage — focus on filling knowledge gaps from official sources
Short bursts + free official tools + your experience = solid prep. You’ve got this! 🚀
